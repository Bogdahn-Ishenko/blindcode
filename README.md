# Codeform

Codeform is a code typing trainer for practicing accuracy and speed with real programming snippets.

## Stack

React 18, TypeScript, Vite, and Tailwind CSS.

## Features

- Strict character-by-character typing with automatic indentation
- Exercises in JavaScript, Python, Scala, PHP, Java, C#, Go, Rust, and C++
- Syntax-highlighted editor with live WPM, CPM, and accuracy statistics
- ANSI QWERTY keyboard with finger-zone guidance
- Russian and English interface

## Run locally

```sh
npm install
npm run dev
```
